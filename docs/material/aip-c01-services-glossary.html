AIP-C01 · In-Scope AWS Services

Quick glossary — what each service is · reference
Machine Learning category is the heart of this exam
orange dot = appears very frequently in exam scenarios ·   purple category = Machine Learning (highest yield)

Machine Learning core of the exam

Amazon Bedrock Managed access to foundation models (Claude, Titan, Llama, Nova) via one API; hub for RAG, agents, guardrails, evaluation.
Bedrock AgentCoreRuntime/infrastructure for building and running production agentic AI (memory, tools, orchestration).
Bedrock Knowledge Bases Managed RAG — ingest docs, chunk, embed, store vectors, retrieve; RetrieveAndGenerate returns answers + citations.
Bedrock Prompt Management Store/version prompt templates with {{variables}}, approval workflows; IAM controls who edits/publishes.
Bedrock Prompt FlowsNo-code builder for sequential prompt chains with conditional branching and pre/post-processing.
Amazon Comprehend NLP service — sentiment, entities, key phrases, language, and PII detection in text.
Amazon KendraIntelligent enterprise search over documents using natural-language queries.
Amazon LexBuild conversational chatbots/voice bots (intents, slots) — powers Alexa-style dialog.
Amazon Q Business Managed GenAI assistant over enterprise data; RBAC via IAM Identity Center + connectors, minimal ops.
Amazon Q Business AppsPurpose-built lightweight apps built on top of Q Business.
Amazon Q DeveloperAI coding assistant — generate/refactor code, API help, test and optimize.
Amazon RekognitionImage/video analysis — object detection, celebrity recognition, moderation. (Images, never text PII.)
Amazon SageMaker AI End-to-end ML platform — train, tune, deploy, host endpoints (real-time / async / batch / serverless).
SageMaker ClarifyDetect bias and class imbalance in data/models; explainability (feature importance).
SageMaker Data WranglerLow-code data prep — clean, transform, normalize tabular/text data for ML.
SageMaker Ground TruthData labeling service to build training datasets (GT Plus = AWS-managed workforce).
SageMaker JumpStartPrebuilt models and solution templates you can deploy/fine-tune quickly.
SageMaker Model MonitorMonitor deployed models for data/quality/drift against a baseline; needs custom container for embeddings.
SageMaker Model RegistryVersion, catalog and manage model deployment + rollback.
SageMaker NeoCompile/optimize models to run faster on target hardware.
SageMaker ProcessingRun data processing / feature engineering / batch jobs on managed compute.
SageMaker Unified StudioSingle IDE unifying data, analytics and AI development.
Amazon Augmented AI (A2I) Human-in-the-loop review of AI-generated output/predictions; feeds corrections back for retraining.
Amazon TextractExtract text, forms, tables (and Queries) from scanned documents/PDFs.
Amazon TitanAmazon's own FM family (text, embeddings) available in Bedrock.
Amazon TranscribeSpeech-to-text; Transcribe Medical for clinical audio.
Bedrock Data Automation (BDA) Managed multimodal extraction (docs + audio + video); 1 project → many blueprints, auto-detects blueprint by type. (In ML/Bedrock scope.)

Application Integration

Amazon AppFlowNo-code data flows between SaaS apps and AWS.
AWS AppConfig Dynamic runtime config with instant propagation — switch models/settings without redeploy.
Amazon EventBridge Event bus; rules route events (e.g. S3 upload) directly to targets like Step Functions.
Amazon SNSPub/sub notifications (fan-out to many subscribers).
Amazon SQS Managed message queue for async decoupled processing (red flag for real-time).
AWS Step Functions Serverless workflow orchestration; ReAct patterns, approval flows, direct service API calls.

Compute

AWS App RunnerDeploy containerized web apps/APIs without managing infra.
Amazon EC2Virtual servers; full control, you manage OS/scaling.
AWS Lambda Serverless functions — glue logic, model invocation, routing, validation.
Lambda@EdgeRun Lambda at CloudFront edge locations, close to users.
AWS OutpostsAWS hardware on-premises for local/low-latency + data residency.
AWS WavelengthAWS compute at telco 5G edge for ultra-low latency.

Containers

Amazon ECRContainer image registry (e.g. custom Model Monitor images).
Amazon ECSContainer orchestration (e.g. host complex MCP servers).
Amazon EKSManaged Kubernetes.
AWS FargateServerless containers — no server management for ECS/EKS.

Database

Amazon Aurora MySQL/PostgreSQL-compatible DB; pgvector for vector search.
Amazon DocumentDBManaged MongoDB-compatible document database.
Amazon DynamoDB NoSQL, low-latency, scalable; TTL for auto-expiry, GSI for metadata search — ideal for conversation history.
DynamoDB StreamsChange-data capture stream from DynamoDB tables.
Amazon ElastiCacheIn-memory cache (Redis/Memcached); MemoryDB variant for durable in-memory + vector.
Amazon NeptuneGraph database; Neptune Analytics adds vector similarity.
Amazon RDSManaged relational DB (Postgres/MySQL/etc.).

Security, Identity & Compliance

Amazon Cognito User auth/identity; user pools + groups for workforce and role-based access.
AWS Encryption SDKClient-side encryption library.
IAM Identities, roles and policies — the real mechanism for RBAC/least privilege.
IAM Access AnalyzerFinds resources shared externally / over-permissive access.
IAM Identity Center Central workforce SSO + permission sets; RBAC source for Q Business.
AWS KMSManaged encryption keys for data at rest.
Amazon MacieDiscovers/classifies PII in S3 (storage-level, not text-pipeline).
AWS Secrets ManagerStore/rotate secrets, API keys, DB credentials.
AWS WAFWeb app firewall — filter/rate-limit HTTP requests (e.g. ahead of API Gateway).

Management & Governance

AWS Auto ScalingScale capacity to demand automatically.
AWS CloudTrail Records API activity for audit (who did what) — not prompt/response content.
Amazon CloudWatch Metrics, dashboards, alarms; token usage, latency, throttling.
CloudWatch LogsCentralized log storage/query (Logs Insights).
CloudWatch SyntheticsSynthetic canaries that test endpoints/workflows.
AWS Cost Anomaly DetectionML-based alerts on unexpected cost spikes.
AWS Cost ExplorerVisualize and analyze AWS spend.
Amazon Managed GrafanaManaged dashboards/visualization.
AWS Service CatalogCurated, approved products for self-service deployment.
AWS Systems ManagerOps management, automation runbooks, Parameter Store (static config).
AWS Well-Architected ToolReview workloads vs best practices; GenAI Lens for GenAI design (review, not enforcement).

Networking & Content Delivery

Amazon API Gateway Managed API front door — request validation, streaming, rate limiting, auth.
AWS AppSyncManaged GraphQL APIs with real-time/subscriptions.
Amazon CloudFrontCDN for content delivery/edge caching (not a token/secret store).
Elastic Load BalancingDistribute traffic across targets.
AWS Global AcceleratorRoute users to optimal endpoints over the AWS network.
AWS PrivateLink Private connectivity to services without public internet (interface VPC endpoints).
Amazon Route 53DNS and health-check routing.
Amazon VPC Isolated network; VPC endpoints keep traffic off the public internet.

Storage

Amazon EBSBlock storage volumes for EC2.
Amazon EFSManaged shared file system.
Amazon S3 Object storage — data lake, docs, datasets (JSONL), model artifacts, logs.
S3 Intelligent-TieringAuto-moves objects between tiers to save cost.
S3 Lifecycle policies Rules to expire/delete (retention limit) or transition to archival — pick delete for "not retained longer than necessary".
S3 Cross-Region ReplicationReplicate objects to another Region.

Analytics

Amazon AthenaServerless SQL queries over data in S3.
Amazon EMRManaged big-data processing (Spark/Hadoop).
AWS Glue Serverless ETL + Data Catalog + Data Quality; tracks data lineage.
Amazon KinesisReal-time streaming data ingestion/processing.
Amazon OpenSearch Service Search + vector database (k-NN, HNSW); Neural plugin integrates with Bedrock; hybrid search.
Amazon QuickSightBI dashboards for business/leadership reporting.
Amazon MSKManaged Apache Kafka streaming.

Developer Tools

AWS AmplifyBuild/host web & mobile front-ends with declarative UI.
AWS CDKInfrastructure as code in a programming language.
AWS CloudFormation IaC templates; StackSets deploy resources (e.g. guardrails) across accounts.
CodeArtifactManaged artifact/package repository.
CodeBuildManaged CI build service.
CodeDeployAutomated deployment (blue/green, canary).
CodePipelineCI/CD orchestration pipeline.
KiroAgentic AI IDE for spec-driven development.
AWS X-Ray Distributed tracing across services (trace FM API calls).

Customer Engagement · Migration & Transfer

Amazon ConnectCloud contact center; integrates with Lex/AI for support.
AWS DataSyncMove large data between on-prem and AWS storage.
AWS Transfer FamilyManaged SFTP/FTPS/FTP into S3/EFS.
